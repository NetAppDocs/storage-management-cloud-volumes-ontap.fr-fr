= Gérer les licences basées sur la capacité pour Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: https://docs.netapp.com/us-en/console-licenses-subscriptions/media/


[role="lead lead"]
Gérez vos licences basées sur la capacité depuis la NetApp Console pour vous assurer que votre compte NetApp dispose d'une capacité suffisante pour vos systèmes Cloud Volumes ONTAP .

Les licences basées sur la capacité vous permettent de payer Cloud Volumes ONTAP par TiB de capacité.

Vous pouvez gérer les licences Cloud Volumes ONTAP basées sur la capacité depuis la NetApp Console.


NOTE: Bien que l'utilisation et la mesure réelles des produits et services gérés dans la Console soient toujours calculées en Gio et Tio, les termes Go/Gio et To/Tio sont utilisés indifféremment. Cela se reflète dans les annonces du Cloud Marketplace, les devis, les descriptions des annonces et dans d'autres documents d'assistance.

https://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/concept-licensing.html["En savoir plus sur les licences Cloud Volumes ONTAP"^].



[[how-licenses-are-added-to-netapp-console]]
== Comment les licences sont ajoutées à la NetApp Console

Après l'achat d'une licence auprès de votre représentant commercial NetApp, NetApp vous enverra un courriel contenant le numéro de série et des informations complémentaires sur la licence.

Entre-temps, la Console interroge automatiquement le service de licences de NetApp pour obtenir les détails concernant les licences associées à votre compte NetApp Support Site. Si aucune erreur n'est détectée, elle ajoute les licences.

Si la Console ne parvient pas à ajouter la licence, vous devrez les ajouter manuellement. Par exemple, si l'agent de la Console est installé dans un emplacement sans accès à Internet, vous devrez ajouter les licences vous-même. https://docs.netapp.com/us-en/bluexp-digital-wallet/task-manage-data-services-licenses.html#add-a-license["Découvrez comment ajouter les licences achetées à votre compte"^]



[[view-the-consumed-capacity-in-your-account]]
== Consultez la capacité consommée sur votre compte

La console affiche la capacité totale consommée sur votre compte ainsi que la capacité consommée par forfait de licences. Cela peut vous aider à comprendre comment vous êtes facturé et si vous devez acheter de la capacité supplémentaire.

.Étapes
. Dans le volet de navigation de gauche, sélectionnez *Administration > Licenses and subscriptions*.
. Dans l'onglet *Aperçu*, la vignette Cloud Volumes ONTAP affiche la capacité actuellement provisionnée pour votre compte.
+
image:screenshot_cvo_licensing_card.png["largeur=300 une capture d'écran affichant le résumé de capacité de vos Licenses and subscriptions Cloud Volumes ONTAP."]

+
** _Direct license_ correspond à la capacité totale provisionnée de tous les systèmes Cloud Volumes ONTAP de votre compte NetApp. La facturation est basée sur la taille provisionnée de chaque volume, indépendamment de l’espace local, utilisé, stocké ou effectif au sein du volume.
** _Contrat annuel_ correspond à la capacité totale sous licence (bring your own license (BYOL) ou Marketplace Contract) que vous avez achetée auprès de NetApp.
** _PAYGO_ correspond à la capacité totale provisionnée via les abonnements du cloud marketplace. La facturation via PAYGO est utilisée uniquement si la capacité consommée dépasse la capacité sous licence ou si aucune licence BYOL n'est disponible dans la NetApp Console.


. Sélectionnez *Afficher* pour voir la capacité consommée pour chacun de vos forfaits de licences.
. Sélectionnez l'onglet *Licenses* pour afficher les détails de chaque licence que vous avez achetée.
+
Pour mieux comprendre les capacités affichées pour le forfait Essentials, vous devez vous familiariser avec le fonctionnement de la facturation. https://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/concept-licensing.html#notes-about-charging["Découvrez la tarification du forfait Essentials"^]

. Sélectionnez l'onglet *Abonnements* pour consulter la capacité consommée par modèle de consommation de licence. Cet onglet inclut à la fois les licences PAYGO et les licences avec contrat annuel.
+
Vous ne verrez que les abonnements associés à l'organisation que vous consultez actuellement.

. Lorsque vous consultez les informations relatives à vos abonnements, vous pouvez interagir avec les détails du tableau. Développez une ligne pour afficher plus de détails.
+
** Sélectionnez image:icon-column-selector.png["l'icône plus à la fin de l'en-tête du tableau"] pour choisir les colonnes à afficher dans le tableau. Notez que les colonnes Term et Auto Renew ne sont pas affichées par défaut. La colonne Auto Renew affiche les informations de renouvellement uniquement pour les contrats Azure.

[[change-charging-methods]]
== Modifier les méthodes de facturation

La licence basée sur la capacité est disponible sous la forme d'un _package_. Lorsque vous créez un système Cloud Volumes ONTAP, vous pouvez choisir parmi plusieurs packages de licences en fonction des besoins de votre entreprise. Si vos besoins changent après la création du système, vous pouvez modifier le package à tout moment. Par exemple, vous pouvez passer du package Essentials au package Professional.

https://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/concept-licensing.html["En savoir plus sur les formules de licences basées sur la capacité"^].

.À propos de cette tâche
* Le changement de méthode de facturation n'affecte pas le fait que vous soyez facturé via une licence achetée auprès de NetApp (BYOL) ou via l'abonnement à la carte (PAYGO) de votre fournisseur de cloud.
+
La Console tente toujours d'abord de facturer une licence. Si une licence n'est pas disponible, elle facture un abonnement Marketplace. Vous n'avez pas à convertir un abonnement BYOL en abonnement Marketplace ou inversement.

* Si vous avez une offre ou un contrat privé provenant de la place de marché de votre fournisseur de cloud, le passage à une méthode de facturation non incluse dans votre contrat entraînera une facturation selon le modèle BYOL (si vous avez acheté une licence auprès de NetApp) ou PAYGO.


.Étapes
. Dans le volet de navigation de gauche, sélectionnez *Administration > Licenses and subscriptions*.
. Sélectionnez l’onglet *Overview*.
. Sur la vignette Cloud Volumes ONTAP, sélectionnez *Afficher*.
. Sélectionnez *Passer à la vue avancée*.
+
image:screenshot_licensing.png["Capture d'écran du bouton « Passer à l'affichage classique »"]

. Faites défiler vers le bas jusqu'au tableau *Licence basée sur la capacité* et sélectionnez *Changer le mode de facturation*.
+
image:screenshot-digital-wallet-charging-method-button.png["Capture d'écran de la page Cloud Volumes ONTAP dans la Console, où le bouton « Changer le mode de facturation » se trouve juste au-dessus du tableau."]

. Dans la fenêtre contextuelle *Modifier le mode de facturation*, sélectionnez un système Cloud Volumes ONTAP, choisissez le nouveau mode de facturation, puis confirmez que vous comprenez que la modification du type de forfait affectera les frais de service.
. Sélectionnez *Changer la méthode de facturation*.




[[download-usage-reports]]
== Télécharger les rapports d'utilisation

Vous pouvez télécharger quatre rapports d'utilisation depuis la NetApp Console. Ces rapports d'utilisation fournissent des détails sur la capacité de vos abonnements et vous indiquent comment vous êtes facturé pour les ressources dans vos abonnements Cloud Volumes ONTAP. Les rapports téléchargeables capturent les données à un instant donné et peuvent être facilement partagés avec d'autres personnes.

image:screenshot-download-usage-report.png["La capture d'écran montre la page des licences basées sur la capacité de Cloud Volumes ONTAP et met en évidence le bouton du rapport d'utilisation."]

Les rapports suivants sont disponibles au téléchargement. Les valeurs de capacité indiquées sont en TiB.

* *Utilisation globale* : Ce rapport récapitule la capacité totale consommée sur votre compte et la détaille par mode de facturation (licences pré-engagées ou paiement à l’utilisation). Il inclut les informations suivantes :
+
[cols="1,2"]
|===
| Colonne | Description 


| Capacité totale consommée | La capacité totale provisionnée sur l'ensemble des systèmes Cloud Volumes ONTAP de votre compte. 


| Capacité totale préengagée | La capacité totale sous licence que vous avez achetée auprès de NetApp, incluant les licences BYOL et les contrats Marketplace. Cette valeur correspond à la somme de la capacité BYOL totale et de la capacité totale des contrats Marketplace. 


| Capacité totale BYOL | La partie de la capacité pré-engagée couverte par les licences bring your own license (BYOL) que vous avez achetées directement auprès de NetApp. 


| Capacité totale des contrats Marketplace | La portion de capacité pré-engagée couverte par des contrats annuels sur le marketplace ou des offres privées achetées via le marketplace de votre fournisseur de cloud. 


| Capacité totale PAYGO | La portion de capacité consommée qui n'est couverte par aucune licence pré-engagée et qui est facturée aux tarifs horaires du marketplace du paiement à l'utilisation (PAYGO). 
|===
* *Utilisation des packages Cloud Volumes ONTAP* : Ce rapport présente la même ventilation de la capacité que le rapport d’utilisation global, mais organisée par package de licences. Il inclut les informations suivantes :
+
[cols="1,2"]
|===
| Colonne | Description 


| Capacité totale consommée | La capacité totale provisionnée pour ce package sur l'ensemble des systèmes Cloud Volumes ONTAP de votre compte. 


| Capacité totale préengagée | La capacité totale sous licence pour ce forfait que vous avez acheté auprès de NetApp, incluant les licences BYOL et les contrats Marketplace. Cette valeur correspond à la somme de la capacité BYOL totale et de la capacité totale des contrats Marketplace. 


| Capacité totale BYOL | La partie de la capacité pré-engagée pour ce forfait couverte par les licences bring your own license (BYOL) que vous avez achetées directement auprès de NetApp. 


| Capacité totale des contrats Marketplace | La portion de capacité pré-engagée pour ce forfait couverte par des contrats annuels sur le marketplace ou des offres privées achetées via le marketplace de votre fournisseur de cloud. 


| Capacité totale PAYGO | La portion de capacité consommée pour ce forfait qui n'est couverte par aucune licence pré-engagée et qui est facturée aux tarifs horaires du marketplace en paiement à l'utilisation (PAYGO). 
|===
* *Utilisation des machines virtuelles de stockage* : Ce rapport montre comment la capacité facturée est répartie entre les systèmes Cloud Volumes ONTAP et les machines virtuelles de stockage (SVM). Ces informations sont uniquement disponibles dans le rapport. Il contient les informations suivantes :
+
[cols="1,2"]
|===
| Colonne | Description 


| ID et nom du système | L'identifiant unique (UUID) et le nom d'affichage du système Cloud Volumes ONTAP. 


| Cloud | Le fournisseur de cloud sur lequel le système est déployé (par exemple, AWS, Azure ou Google Cloud). 


| ID de compte NetApp | L'identifiant du compte NetApp associé au système. 


| Configuration du système | La configuration de déploiement du système (par exemple, nœud unique ou paire haute disponibilité). 


| Nom SVM | Le nom de la machine virtuelle de stockage (SVM) au sein du système Cloud Volumes ONTAP. 


| Capacité provisionnée | La capacité totale provisionnée sur le SVM. 


| Récapitulatif de la capacité facturée | La capacité effectivement facturée pour la SVM. Chaque SVM a une capacité facturable minimale (4 Tio par défaut, bien que cela puisse varier selon le compte). Si la capacité provisionnée de la SVM est inférieure ou égale à ce minimum, cette valeur est arrondie au minimum ; sinon, elle est égale à la capacité provisionnée. 


| Terme de facturation Marketplace | La période de facturation de l'abonnement associé à la marketplace (par exemple, horaire ou annuel). 


| Cloud Volumes ONTAP package ou fonctionnalité | Le pack de licences ou la fonctionnalité (par exemple, Essentials ou Professional) associé(e) au SVM. 


| Nom de l’abonnement SaaS Marketplace de facturation | Le nom de l’abonnement à la marketplace utilisé pour la facturation. 


| ID d'abonnement Marketplace SaaS de facturation | L'identifiant unique de l'abonnement marketplace utilisé pour la facturation. 


| Type de charge de travail | Indique si les volumes du SVM sont *Primaires* (lecture/écriture), activement utilisés pour les données de production, ou *Secondaires* (DP), volumes de destination de protection des données tels que les répliques SnapMirror utilisées pour la sauvegarde et la réplication. 
|===
* *Utilisation des volumes* : Ce rapport montre comment la capacité facturée est répartie par volumes dans un système Cloud Volumes ONTAP. Ces informations ne sont disponibles sur aucun écran de la Console. Elles comprennent les informations suivantes :
+
[cols="1,2"]
|===
| Colonne | Description 


| ID et nom du système | L'identifiant unique (UUID) et le nom d'affichage du système Cloud Volumes ONTAP qui contient le volume. 


| Nom SVM | Le nom de la machine virtuelle de stockage (SVM) qui contient le volume. 


| ID du volume | L'identifiant unique du volume. 


| Type de volume | Le type de volume (par exemple, lecture-écriture ou protection des données). 


| Capacité provisionnée en volume | La capacité totale provisionnée pour le volume. 
|===
+

NOTE: FlexClone volumes ne sont pas inclus dans ce rapport car ces types de volumes n'entraînent pas de frais.



.Étapes
. Dans le volet de navigation de gauche, sélectionnez *Administration > Licenses and subscriptions*.
. Dans l'onglet *Aperçu*, sélectionnez *Afficher* dans la vignette Cloud Volumes ONTAP.
. Sélectionnez *Rapport d'utilisation*.
+
Le rapport d'utilisation se télécharge.

. Ouvrez le fichier téléchargé pour accéder aux rapports.
