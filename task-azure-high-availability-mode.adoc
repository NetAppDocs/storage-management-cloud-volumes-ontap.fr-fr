= Activer le mode haute disponibilité pour Cloud Volumes ONTAP dans Azure
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Activez le mode haute disponibilité (HA) de Microsoft Azure pour votre paire haute disponibilité Cloud Volumes ONTAP afin de réduire les temps de basculement imprévus et de prendre en charge NFSv4. Ce mode peut offrir un objectif de temps de reprise (RTO) de 60 secondes pour les clients CIFS et NFSv4 lors de basculements imprévus.

À partir de Cloud Volumes ONTAP 9.10.1, nous avons réduit le temps de basculement non planifié pour les paires haute disponibilité Cloud Volumes ONTAP exécutées dans Microsoft Azure et ajouté la prise en charge de NFSv4. Pour rendre ces améliorations disponibles pour Cloud Volumes ONTAP, vous devez activer la fonctionnalité HA sur votre abonnement Azure.

.À propos de cette tâche
La NetApp Console affiche une invite lorsque vous devez activer cette fonctionnalité sur un abonnement Azure. Veuillez noter les points suivants :

* Cette fonctionnalité fonctionne avec ONTAP pour réduire la durée d'indisponibilité des applications observée par les clients NFS lors de basculements imprévus. Son activation n'indique pas de problème de disponibilité de votre paire haute disponibilité Cloud Volumes ONTAP.
* L’activation de cette fonctionnalité Azure ne perturbe pas les paires haute disponibilité Cloud Volumes ONTAP.
* L'activation de cette fonctionnalité sur votre abonnement Azure n'affecte pas les autres machines virtuelles de votre environnement ni aucun système à nœud unique au sein du même abonnement.
* Lors des basculements, Cloud Volumes ONTAP utilise un équilibreur de charge Azure interne pour les LIF de gestion du cluster et des SVM qui desservent les clients CIFS et NFS.
* Lorsque vous activez le mode HA, la Console analyse le système toutes les 12 heures afin de mettre à jour les règles internes de l’Azure Load Balancer.


.Étapes
Utilisez Azure CLI pour activer la fonctionnalité en tant qu’utilisateur Azure disposant des privilèges _Owner_.

. https://docs.microsoft.com/en-us/azure/cloud-shell/quickstart["Accéder à Azure Cloud Shell depuis le portail Azure"^]
. Enregistrer la fonctionnalité du mode haute disponibilité :
+
[source, azurecli]
----
az account set -s AZURE_SUBSCRIPTION_NAME_OR_ID
az feature register --name EnableHighAvailabilityMode --namespace Microsoft.Network
az provider register -n Microsoft.Network
----
. Vérifiez éventuellement que la fonctionnalité est désormais enregistrée :
+
[source, azurecli]
----
az feature show --name EnableHighAvailabilityMode --namespace Microsoft.Network
----
+
L'interface de ligne de commande Azure doit renvoyer un résultat similaire au suivant :

+
[listing]
----
{
  "id": "/subscriptions/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/providers/Microsoft.Features/providers/Microsoft.Network/features/EnableHighAvailabilityMode",
  "name": "Microsoft.Network/EnableHighAvailabilityMode",
  "properties": {
    "state": "Registered"
  },
  "type": "Microsoft.Features/providers/features"
}
----
