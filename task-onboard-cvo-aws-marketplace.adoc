= Abonnez-vous et déployez Cloud Volumes ONTAP depuis AWS Marketplace
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Abonnez-vous à Cloud Volumes ONTAP depuis AWS Marketplace et laissez la NetApp Console vous guider tout au long de la prise en main. Avec un parcours simple de l’abonnement au déploiement, vous pouvez rapidement commencer à utiliser Cloud Volumes ONTAP. L’expérience guidée simplifie le processus, de l’abonnement AWS Marketplace au déploiement, vous aidant à déployer Cloud Volumes ONTAP sans nécessiter une expertise approfondie en cloud ou en ONTAP.

L’abonnement et le déploiement de Cloud Volumes ONTAP depuis AWS Marketplace comprennent les étapes suivantes :

* Abonnement à Cloud Volumes ONTAP dans AWS Marketplace.
* Inscrivez-vous à la NetApp Console.
* Création de votre organisation (si nécessaire) et association de l’abonnement à la marketplace.
* Déploiement d'un agent de Console dans AWS.
* Ajout de votre premier système Cloud Volumes ONTAP.


L'intégration simplifiée offre un déploiement automatisé des agents, nécessitant une intervention minimale de votre part pour l'association à l'abonnement, la configuration des rôles IAM, le provisionnement des agents et l'initialisation du système. L'orchestration du backend gère automatiquement la création de la pile CloudFormation, la validation de la connectivité VPC et les dépendances des ressources. Cela réduit les étapes de configuration manuelle et les transitions d'écran, ce qui vous permet de déployer Cloud Volumes ONTAP plus rapidement, avec moins d'erreurs de configuration et d'interruptions. Au fur et à mesure de l'avancement du déploiement, vous pouvez suivre votre progression dans le panneau de droite.

.Avant de commencer
Examinez ces prérequis avant de commencer le workflow d'intégration.

* Vous devez posséder un compte AWS disposant des autorisations nécessaires pour vous abonner à AWS Marketplace. Pour utiliser la configuration IAM automatisée, vous devez être administrateur AWS ou disposer des autorisations indiquées ci-dessous.
+
[source, json]
----
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "CloudFormationStack",
      "Effect": "Allow",
      "Action": [
        "cloudformation:CreateStack",
        "cloudformation:DeleteStack",
        "cloudformation:DescribeStacks",
        "cloudformation:DescribeStackEvents",
        "cloudformation:GetTemplateSummary",
        "iam:CreateRole",
        "iam:DeleteRole",
        "iam:GetRole",
        "iam:PutRolePolicy",
        "iam:DeleteRolePolicy",
        "iam:GetRolePolicy",
        "iam:PassRole",
        "lambda:CreateFunction",
        "lambda:DeleteFunction",
        "lambda:GetFunction",
        "lambda:InvokeFunction"
  ]
}
----
* Vous pouvez créer ou utiliser des rôles IAM dans AWS pour le déploiement d’agents.
* Vous pouvez vous connecter ou créer un compte dans la NetApp Console.


Pour connaître les prérequis complets de déploiement de l'agent AWS, consultez link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html["Déployez un agent NetApp Console depuis AWS Marketplace"^].



[[subscribe-in-aws-marketplace]]
== Abonnez-vous dans AWS Marketplace

Démarrez le processus d'intégration en localisant l'offre Cloud Volumes ONTAP dans AWS Marketplace.

.Étapes
. Accédez à AWS Marketplace en utilisant votre compte AWS.
. Localisez l’offre NetApp Cloud Volumes ONTAP. Il existe deux offres Cloud Volumes ONTAP dans AWS Marketplace :
+
** L'offre autonome pour les abonnements annuels à Cloud Volumes ONTAP
** L’offre combinée NetApp Intelligent Service (NIS) pour les services de données NetApp et les abonnements Cloud Volumes ONTAP. Choisissez l’offre _autonome_ pour ce processus d’intégration.


. Consultez les détails de l'annonce et les conditions tarifaires.
. Abonnez-vous et finalisez votre commande.
. Après votre inscription, AWS vous redirige vers la page d'inscription ou de connexion à la Console.




[[sign-up-or-sign-in-to-netapp-console]]
== Inscrivez-vous ou connectez-vous à la NetApp Console

Accédez à la NetApp Console pour poursuivre la configuration une fois votre abonnement à la marketplace terminé.

.Étapes
. Sur la page Console, sélectionnez-en une :
+
** *Inscrivez-vous* si vous êtes un nouvel utilisateur.
** *Connectez-vous à la NetApp Console* si vous possédez déjà un compte.


. Si vous avez sélectionné *S'inscrire*, complétez les informations suivantes :
+
.. Saisissez les champs obligatoires :
+
*** Messagerie électronique
*** Mot de passe
*** Nom complet
*** Entreprise
*** Pays


.. Sélectionnez *Suivant*.
.. Facultatif : Saisissez des coordonnées telles que l’adresse, la ville, l’état, le code postal et le numéro de téléphone.
.. Sélectionnez *Sign up*.
.. Acceptez les termes de la licence.
.. Vérifiez votre adresse e-mail à l’aide du message provenant de service@console.netapp.com.


. Connectez-vous à la Console et terminez l'authentification.




[[create-your-organization]]
== Créez votre organisation

Effectuez cette étape uniquement si vous êtes un nouvel utilisateur ou si vous n'appartenez pas déjà à une organisation NetApp Console.

Si vous appartenez déjà à une organisation, passez cette section et continuez à <<Associez votre abonnement>>.

Créez une organisation pour gérer les utilisateurs, les rôles, les autorisations, les licences et les systèmes.

.Étapes
. Saisissez un nom d'organisation.
. Facultatif : associer un compte NetApp Support Site (NSS).
. Sélectionnez *Créer*.




[[associate-your-subscription]]
== Associez votre abonnement

Après avoir créé votre organisation, la Console tente automatiquement de lier votre abonnement à la place de marché à l'organisation.

Si l'association automatique échoue, associez manuellement votre abonnement. link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-subscriptions.html["Découvrez comment gérer vos abonnements"^].



[[deploy-a-console-agent-in-aws]]
== Déployez un agent Console dans AWS

Une fois l’abonnement associé, la NetApp Console ouvre automatiquement le flux de déploiement de l’agent pour gérer vos ressources AWS et vos systèmes Cloud Volumes ONTAP.

Pour en savoir plus sur les autorisations utilisées lors du déploiement de l’agent, consultez link:https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html["Référence des autorisations AWS"^].

.Étapes
. Vous pouvez suivre les étapes mentionnées sur la page d'introduction pour obtenir les autorisations minimales nécessaires au déploiement d'un agent, ou continuer à créer automatiquement un rôle pour le déploiement d'un agent.
. Sur la page *Identifiants AWS*, sélectionnez l'une des options suivantes pour fournir les identifiants nécessaires au déploiement de l'agent :
+
[role="tabbed-block"]
====
.Créez un rôle pour moi (recommandé)
--
Sélectionner cette option ouvre un flux AWS CloudFormation Quick Create pour créer le rôle de déploiement de l’agent. Si vous disposez de privilèges d’administrateur, vous pouvez utiliser cette option pour utiliser automatiquement une pile CloudFormation afin de créer la stratégie, le rôle et authentifier l’utilisateur pour créer l’agent.

.. Ajoutez l'ID du compte AWS et, éventuellement, l'ID externe. La Console attribue un nom de rôle par défaut.
.. Acceptez les conditions et sélectionnez *Créer une stack*.
+
image:screenshot-stack-creation.png["largeur=50% Capture d'écran de la page de création de pile AWS CloudFormation où vous saisissez l'ID du compte AWS et, éventuellement, l'ID externe du rôle de déploiement de l'agent."]

.. Une fois le rôle IAM configuré dans AWS et l'ARN généré, confirmez et enregistrez le rôle.


--
.Assumer le rôle
--
Cela fait partie du processus d'attribution manuelle des rôles. Saisissez l'ARN d'un rôle IAM existant. Pour obtenir des informations sur la modification de ce rôle, consultez  https://docs.netapp.com/us-en/console-setup-admin/task-adding-aws-accounts.html#associate-an-existing-subscription-with-your-organization["Gérez les informations d'identification AWS et les abonnements à la marketplace pour la NetApp Console"^].

--
.Clés AWS
--
Cela fait partie du processus d'attribution manuelle des rôles. Saisissez une clé d'accès AWS et une clé secrète AWS. Pour plus d'informations, consultez https://docs.netapp.com/us-en/console-setup-admin/task-adding-aws-accounts.html#add-the-credentials-to-an-existing-agent["Gérez les informations d'identification AWS et les abonnements à la marketplace pour la NetApp Console"^].

--
====
. Déployez l'agent AWS :
+
.. Sur la page *AWS agent details*, définissez ou confirmez le nom de l'instance de l'agent et le rôle de l'agent.
.. Sur la page *Réseau*, sélectionnez VPC, sous-réseau, paire de clés, comportement de l'adresse IP publique et paramètres de proxy.
.. Configurez le *groupe de sécurité*. Autorisez l'accès entrant HTTP (80), HTTPS (443) et SSH (22) pour le dépannage de l'accès à la VM de l'agent.


. Consultez les résumés des sections et sélectionnez *Ajouter* pour déployer.
+
Pour connaître l'ensemble des exigences en matière de réseau et d'autorisations, consultez :

+
** https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html#step-1-set-up-networking["Configurer le réseau pour le déploiement sur AWS Marketplace"^]
** https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-marketplace.html#step-2-set-up-aws-permissions["Configurer les autorisations AWS"^]
** https://docs.netapp.com/us-en/console-setup-admin/reference-permissions-aws.html["Référence des autorisations AWS"^]


. Suivez la progression du déploiement jusqu'à son terme. Vous pouvez développer les journaux d'événements pour consulter l'activité détaillée.


.Après avoir terminé
Une fois le déploiement terminé, vous pouvez créer votre premier système Cloud Volumes ONTAP ou rester sur la page Systèmes pour ajouter un système ultérieurement.



[[add-your-first-cloud-volumes-ontap-system]]
== Ajoutez votre premier système Cloud Volumes ONTAP

Une fois l'agent prêt, créez votre premier système Cloud Volumes ONTAP dans AWS.

.Étapes
. À partir de l'invite post-déploiement, sélectionnez *Ajouter un système*.
. Démarrez le workflow de création du système Cloud Volumes ONTAP.
. Finalisez la configuration du système.


Pour des instructions détaillées sur le déploiement du système, veuillez vous référer à https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-quick-deploy-aws.html["Déployez Cloud Volumes ONTAP avec Quick create"^].



[[troubleshooting-and-recovery]]
== Dépannage et récupération

Utilisez cette section si vous quittez le processus d'intégration avant la fin ou si le déploiement de l'agent échoue. Ces étapes vous aident à reprendre là où vous vous êtes arrêté ou à récupérer et réessayer le déploiement.



[[resume-setup]]
=== Reprendre la configuration

Si vous quittez avant la fin, vous pouvez reprendre la configuration à partir de la dernière étape terminée.

.Étapes
. Accédez à la page d'accueil de la NetApp Console.
. Sélectionnez *Reprendre la configuration* pour poursuivre l'intégration.




[[recover-from-deployment-failure]]
=== Récupérez après un échec de déploiement

En cas d'échec du déploiement :

.Étapes
. Téléchargez le rapport de déploiement.
. Vérifiez votre configuration et vos journaux.
. Sélectionnez *Recommencer* pour réessayer le déploiement.
+
link:https://docs.netapp.com/us-en/console-setup-admin/task-troubleshoot-agent.html["Apprenez à résoudre les problèmes liés aux agents"^].
