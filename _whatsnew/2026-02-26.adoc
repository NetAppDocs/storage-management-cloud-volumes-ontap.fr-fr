=== Prise en charge de Google Infrastructure Manager pour les déploiements en mode privé

Cloud Volumes ONTAP 9.16.1 et les versions ultérieures prennent désormais en charge  https://docs.cloud.google.com/infrastructure-manager/docs/overview["Google Cloud Infrastructure Manager"^]Infrastructure Manager (IM) au lieu de  https://docs.cloud.google.com/deployment-manager/docs/deprecations["Cloud Deployment Manager"^]Deployment Manager (DM) pour les nouveaux déploiements en mode privé dans Google Cloud. Google abandonne progressivement Deployment Manager en tant que service d'infrastructure au profit d'Infrastructure Manager, plus avancé.

À compter du 25 février 2026, Cloud Volumes ONTAP utilisera Infrastructure Manager pour les déploiements en mode privé, nouveaux et existants. Le flux de travail de base dépend de votre scénario :

|===

Reportez-vous à https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/reference-networking-gcp.html#infrastructure-manager-configuration-in-private-mode-or-protected-environments["Configuration d'Infrastructure Manager en mode privé ou dans des environnements protégés"^].
