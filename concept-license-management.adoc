= Découvrez les licences BYOL dans Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Le modèle de licence Bring-Your-Own License (BYOL) est un modèle de facturation Cloud Volumes ONTAP dans lequel vous achetez une licence directement auprès de NetApp au lieu d'utiliser un abonnement à une place de marché cloud.

BYOL est disponible pour les déploiements en mode standard et en mode privé, sous réserve de restrictions de disponibilité. Vous pouvez gérer les licences BYOL dans la section *Licences et abonnements* de la NetApp Console sous *Licences directes*. Chaque licence est associée à votre entreprise et à des identifiants spécifiques du site de support NetApp.

* NetApp a restreint l'achat, la prolongation et le renouvellement des licences BYOL pour les déploiements en mode standard disposant d'abonnements valides sur la place de marché. Pour plus d'informations, consultez  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html#restricted-availability-of-byol-licensing-for-cloud-volumes-ontap["Disponibilité restreinte des licences BYOL pour Cloud Volumes ONTAP"^].
* NetApp abandonne progressivement les licences par nœud au profit des licences par capacité. Les licences par nœud restent disponibles pour un nombre limité de déploiements existants, notamment certains déploiements clients de l'USPS et des déploiements en Chine. Pour plus d'informations, voir  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html#end-of-availability-of-node-based-licenses["Fin de disponibilité des licences basées sur des nœuds"^].




[[byol-deployment-modes]]
== Modes de déploiement BYOL

[role="tabbed-block"]
====
.Déploiements en mode standard
--
* Au lieu de BYOL, NetApp préfère les abonnements annuels ou à la carte (PAYGO) via une place de marché pour facturer votre consommation.
* Les déploiements en mode standard utilisent généralement des licences basées sur la capacité plutôt que sur des licences basées sur le nombre de nœuds. Seul un nombre limité de déploiements en mode standard existants utilisent des licences basées sur le nombre de nœuds.


--
.Déploiements en mode privé
--
* Les déploiements en mode privé reposent entièrement sur des licences BYOL, car les abonnements à la marketplace ne sont pas disponibles en mode privé.
* Pour les nouveaux déploiements, utilisez les packages Essentials basés sur la capacité plutôt que les licences par nœud. Les licences par nœud sont utilisées par certains déploiements en mode privé plus anciens.


--
====


[[compare-byol-license-types-in-private-mode]]
=== Comparer les types de licences BYOL en mode privé

Le tableau suivant récapitule les différences entre les licences basées sur la capacité et les licences basées sur les nœuds en mode privé.

[cols="25,37,38"]
|===
| Fonctionnalité | Licences basées sur la capacité | Licences basées sur les nœuds 


| Assistance au déploiement  a| 
Les nouveaux déploiements en mode privé ne prennent en charge que les licences basées sur la capacité, plus précisément le forfait Essentials.
 a| 
Les nouveaux déploiements en mode privé ne prennent pas en charge les licences par nœud. Seul un nombre limité de déploiements existants basés sur des nœuds peuvent continuer à les utiliser.



| Achat  a| 
Achetez un pack BYOL Essentials basé sur la capacité auprès de NetApp et attribuez-le à votre système lors du déploiement.
 a| 
Si vous disposez d'un déploiement en mode privé existant avec une licence basée sur les nœuds, vous pouvez le convertir en licence basée sur la capacité en achetant un package Essentials auprès de NetApp.



| Capacité  a| 
Les 500 premiers Gio de capacité consommée ne sont pas déduits du coût de votre licence. Vous pouvez acheter des modules supplémentaires à mesure que vos besoins en charge de travail augmentent.
 a| 
Une licence par nœud offre jusqu'à 368 Tio de capacité pour un nœud unique ou une paire haute disponibilité. Pour allouer plus de 368 Tio à un système Cloud Volumes ONTAP, achetez plusieurs licences. Par exemple, deux licences offrent jusqu'à 736 Tio et quatre licences offrent jusqu'à 1,4 PiB.



| Portée  a| 
La licence basée sur la capacité utilise un pool de capacité partagé entre vos systèmes Cloud Volumes ONTAP. Vous pouvez redistribuer la capacité disponible en fonction de l'évolution de vos besoins de stockage.
 a| 
Chaque licence par nœud s'applique à un système Cloud Volumes ONTAP et fournit une capacité fixe à ce système.



| Transférabilité  a| 
Chaque licence basée sur la capacité est associée à un compte Console. Les systèmes créés sous ce compte peuvent partager la capacité de la licence et le numéro de série. Par exemple, une licence de 5 Tio peut prendre en charge deux systèmes de 2,5 Tio chacun ou un système de 5 Tio. Vous pouvez consulter le numéro de série de la licence dans la Console et attribuer la même licence à plusieurs systèmes sous le même compte.
 a| 
Vous pouvez transférer une licence BYOL basée sur un nœud en supprimant le système existant et en utilisant la licence pour créer un nouveau système. Seuls les numéros de série _indépendants du cloud_ fonctionnent entre les fournisseurs de cloud. Ces numéros de série commencent par le préfixe _908xxxx_.

|===


[[manage-and-renew-byol-licenses]]
== Gérer et renouveler les licences BYOL



[[renew-a-byol-license]]
=== Renouveler une licence BYOL

Contactez un représentant NetApp pour renouveler votre licence BYOL. La NetApp Console obtient et installe automatiquement la licence renouvelée sur le système Cloud Volumes ONTAP.

Si la NetApp Console ne peut pas accéder au fichier de licence via une connexion Internet sécurisée, téléchargez le fichier de licence et link:task-manage-node-licenses.html["Téléchargez-le manuellement sur la NetApp Console"].

Pour gérer les informations d'identification du site de support NetApp associées à la Console, consultez https://docs.netapp.com/us-en/console-setup-admin/task-adding-nss-accounts.html["Gérer les informations d'identification NSS associées à la NetApp Console"^].



[[respond-to-an-expiration-warning]]
=== Répondre à un avertissement d'expiration

La console affiche un avertissement 30 jours avant l'expiration d'une licence par nœud, puis à nouveau à l'expiration de la licence. Sélectionnez le système Cloud Volumes ONTAP pour consulter l'avertissement et renouveler la licence.

image:screenshot_warning.gif["Capture d'écran : affiche un système Cloud Volumes ONTAP qui inclut une icône d'avertissement.  L'icône indique qu'une action est requise."]

Si vous êtes administrateur d'organisation ou administrateur de compte et que vous avez activé l'option, la NetApp Console inclut un avertissement d'expiration de licence dans le rapport Cloud Volumes ONTAP et vous l'envoie par e-mail.

Si vous ne renouvelez pas la licence avant son expiration, le système Cloud Volumes ONTAP s'arrête. Redémarrer le système sans renouveler la licence entraîne un nouvel arrêt.
