= Découvrez les options d'automatisation de Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Les équipes DevOps utilisent divers outils pour automatiser la configuration et l'administration de leurs environnements d'exécution de centre de données. Outre NetApp Console, vous pouvez utiliser plusieurs de ces technologies pour l'automatisation de Cloud Volumes ONTAP, notamment les API de NetApp Console, les procédures ONTAP CLI et des outils d'automatisation, tels qu'Ansible et Terraform. Les outils d'automatisation externes reposent généralement sur une conception d'infrastructure as Code (IaC).

Utilisez https://labondemand.netapp.com/["Lab on Demand"^] pour vous entraîner à automatiser Cloud Volumes ONTAP.



[[netapp-console-apis]]
== API de NetApp Console

La NetApp Console fournit des API REST que vous pouvez utiliser pour administrer par programmation les ressources Cloud Volumes ONTAP. Les API prennent en charge des opérations telles que la création et l’administration de systèmes Cloud Volumes ONTAP, ainsi que l’ajout d’agrégats et de volumes sur Amazon Web Services (AWS), Microsoft Azure (Azure) et Google Cloud. Les appels d’API disponibles varient selon le fournisseur de cloud et le type de déploiement, notamment les configurations à nœud unique et les configurations haute disponibilité (HA).

Vous pouvez utiliser les workflows de l’API Cloud Volumes ONTAP pour automatiser un déploiement standard et l’administration ultérieure du stockage. Certains workflows incluent la préparation du déploiement, la création d’un système et l’administration du stockage, avec des workflows spécifiques au fournisseur pour AWS, Azure et Google Cloud.

[[ontap-cli]]
== ONTAP CLI

Vous pouvez utiliser l'interface de ligne de commande ONTAP pour plusieurs tâches d'administration de Cloud Volumes ONTAP. Les procédures et commandes disponibles varient selon la fonctionnalité et le fournisseur de cloud. N'utilisez pas l'interface de ligne de commande ONTAP ni ONTAP System Manager pour mettre à niveau Cloud Volumes ONTAP. Effectuez les mises à niveau depuis la NetApp Console.

[[terraform]]
== Terraform

Terraform est un outil d'orchestration open source qui utilise des fichiers de configuration déclaratifs. NetApp fournit un fournisseur Terraform pour Cloud Volumes ONTAP. Vous pouvez l'utiliser pour automatiser et intégrer votre infrastructure avec l'IaC. Pour plus d'informations, consultez https://registry.terraform.io/providers/NetApp/netapp-cloudmanager/latest["fournisseur Terraform NetApp"^].
